# Font License — Tinos

The `Tinos-*.ttf` files in this folder are the **Tinos** typeface, a
metric-compatible substitute for Times New Roman with full Vietnamese
(Latin Extended) coverage.

- Font: Tinos (by Steve Matteson / Ascender / Google)
- License: SIL Open Font License, Version 1.1 (OFL-1.1)
- Source: https://fonts.google.com/specimen/Tinos

The OFL permits bundling and redistribution of the font files within this
project (including production deployments), so these files are safe to embed
for server-side PDF generation.
